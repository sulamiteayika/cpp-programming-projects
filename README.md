This repository contains beginner C++ projects that I am creating while studying programming and software engineering.

Project 1: Salon Price Calculator

The Salon Price Calculator is a console application designed to calculate a customer’s final service price.

The program asks the user to enter:

* The service price
* Any additional fee
* A discount percentage

It validates the information and calculates the customer’s final total.

Programming Concepts Demonstrated

* Variables and double data types
* User input with cin
* Output with cout
* Functions and return values
* Parameters and arguments
* Conditional statements
* Mathematical calculations
* Input validation
* Formatted decimal output

File

salon_price_calculator.cpp

How to Run

1. Open the file in a C++ compiler, such as Visual Studio.
2. Compile and run the program.
3. Enter the requested prices and discount.
4. The program will display the customer’s final total.
